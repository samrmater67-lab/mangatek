# MangaTek PWA

واجهة ويب قابلة للإضافة إلى الشاشة الرئيسية في iPhone (PWA).

## تشغيلها
1. ارفع محتويات هذا المجلد إلى استضافة HTTPS ثابتة مثل GitHub Pages أو Netlify أو Cloudflare Pages.
2. افتح رابط الموقع المنشور من Safari على iPhone.
3. اضغط مشاركة ثم «إضافة إلى الشاشة الرئيسية» ثم «إضافة».

## المزايا
- بحث ضمن قائمة الأعمال التجريبية المضمنة.
- مفضلة محلية.
- متابعة القراءة وسجل محلي.
- الوضع الليلي والفاتح.
- تبويب لفتح موقع mangatek.com داخل إطار، مع رابط بديل إذا منع الموقع العرض داخل الإطار.
- تخزين واجهة التطبيق مؤقتاً للعمل الأساسي دون اتصال.

## تنبيه مهم
هذه نسخة أولية وليست تطبيقاً أصلياً من App Store. بيانات بطاقات المانجا تجريبية وليست مستوردة من MangaTek. محتوى الموقع قد يمنع العرض داخل iframe بسبب إعدادات الأمان؛ عندها استخدم الرابط المباشر. لا توجد مزامنة مع حساب MangaTek أو استخراج تلقائي للفصول. المفضلة والسجل محفوظان على الجهاز والمتصفح فقط.
